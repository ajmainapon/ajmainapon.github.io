Generative Memorability — Steering Latent Diffusion via Graph-Embedded Spatial Guidance

Integrated AMNet memorability guidance into a Latent Diffusion Model workflow. Steering generation toward more memorable outputs while preserving fidelity. Achieved a +60% memorability uplift across a 20-prompt evaluation set, independently validated with ResMem as a scorer. Extending the pipeline with graph-embedded spatial guidance via custom U-Net modifications and cross-attention steering, benchmarked against Stable Diffusion baselines under faculty supervision.

Active · Independent

Label-Efficient Medical Segmentation via SSL Volumetric Prediction

Designing a label-efficient 3D segmentation pipeline using ViT-Base with Joint-Embedding Predictive Architecture (JEPA), targeting competitive accuracy with only 3–5 annotated volumes. Self-supervised pretraining on 1,200+ unannotated CT scans (TotalSegmentator) to learn global spatial geometry via 90% slice masking. Built a hardware-constrained training workflow on a single 24GB RTX 3090 using AMP and gradient accumulation. Few-shot fine-tuning freezes the ViT backbone and trains a 1×1 Conv decoder, benchmarked against fully supervised nnU-Net baselines.
